# La Casita de Ginger

Sitio web para **La Casita de Ginger**, pastelería temática de Chillán donde la Navidad se vive todo el año.
Proyecto desarrollado de forma individual en la asignatura Diseño Web (IPLACEX), a partir de los antecedentes entregados por el emprendimiento.

| Carpeta | Evaluación | Contenido |
|---|---|---|
| [`ev1-html/`](ev1-html/public_html/index.html) | N°1 – Fundamentos de desarrollo web | Estructura semántica en HTML, sin CSS (4 páginas) |
| [`ev2-css/`](ev2-css/public_html/index.html) | N°2 – Diseño web y CSS | Hoja de estilos externa, Flexbox/Grid, animaciones y página de pedidos (5 páginas). Ver [inventario de imágenes](ev2-css/INVENTARIO-IMAGENES.md) |

## Cómo verlo
Descarga el repositorio y abre `public_html/index.html` de la evaluación que quieras revisar en el navegador.

## Tecnologías
- HTML5 semántico (validado en W3C)
- CSS3: selectores de elemento, clase, id y avanzados; modelo de caja; Flexbox; Grid; `@keyframes`; media queries
- Imágenes optimizadas en JPG y WebP
