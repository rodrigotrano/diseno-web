# Evaluación N°3 – Sitio migrado al template

Versión evaluada de La Casita de Ginger: el contenido y los estilos de las Evaluaciones 1 y 2 migrados al template **Assan Beauty Spa** (Bootstrap 4) entregado en la asignatura, con funcionalidades en JavaScript.

| Carpeta / archivo | Contenido |
|---|---|
| `public_html/` | Sitio publicado (5 páginas) |
| `public_html/css/plugins/plugins.css` | Bootstrap 4 + plugins del template (sin cambios) |
| `public_html/css/style.css` | Tema del template recompilado desde `scss/` con los colores y tipografías de la marca |
| `public_html/css/casita.css` | Capa propia: identidad de la marca, Ginger animado y componentes del pedido |
| `public_html/js/plugins/plugins.js`, `beauty.custom.js` | JavaScript del template (jQuery, Bootstrap, carrusel, galería, animaciones) |
| `public_html/js/pedido.js` | Carrito, validación del formulario y pedido por WhatsApp |
| `public_html/js/horario.js` | Día de hoy y estado «abierto / cerrado» en Contacto |
| `scss/` | Fuentes SCSS del template; se modificaron `_variables.scss` y `style.scss` |

Partes del template que no se usan (Revolution Slider, dzsparallaxer, smart-form PHP, blog, login) no se incluyeron para mantener el sitio liviano.
